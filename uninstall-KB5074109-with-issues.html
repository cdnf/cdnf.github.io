前言

使用笔记本电脑有个习惯，懒得关机直接盖上盖子，下次使用直接打开再登录就行，之前开的网页，开的程序都不用重新打开。中间有时候可能会自动退出休眠费点电，但咱也一直没在乎。

现象

这两天突然发现，每次开盖没有自动恢复到登录界面，电源灯处于呼吸慢闪状态，而且电脑发热严重，说明一直在运转没有进入休眠关机状态，只有长按关机再开机才行。

前两次没在意，以为是自己开的什么程序出错导致没有进入休眠，但连续几次就想到是不是自动安装了系统补丁导致的，进入系统更新历史记录果然发现新装了：KB5074109，卸载之后暂时未出现无法休眠问题。

解决方案

查看系统更新安装记录：按 win 键打开开始》Windows 更新》更新历史记录，在 质量更新 里发现了最新安装记录 KB5074109，点击 了解详细信息 可见该补丁具体内容，我们需要将其卸载验证问题是不是这货导致。

卸载补丁

因为怀疑上了这个最新的补丁，所以卸载验证：更新历史记录 页往下翻有个 卸载更新 点进去，找到 KB5074109 那行点 卸载，按要求重启系统。

卸载后微软默认还是要给你装上的，所以建议 暂停更新 或者 禁用 Windows 更新

暂停更新

还是在 Windows 更新 功能设置页，更多选项下面有个 暂停更新 ，我们可以选择要暂停的时间，最长暂停时间也就一个来月。等再次更新如果这次的补丁有问题一般下次都会修复。

禁用 Windows 更新

如果不放心盖茨的修复效率，我们可以将 Windows 自动更新功能彻底关闭：按 win+X 弹出系统功能菜单》计算机管理》服务和应用程序》服务》找到 Windows 更新 ，双击或右键打开 属性 面板，将该服务停止并将 启动类型 设置为 禁用，以后等盖茨修复问题了或者你自己想更新了再改回来即可。
