前言

有些网址放收藏夹，虽然能用浏览器账号同步，但总归是依赖登录，所以就想弄个在线导航页或网站。

网站就需要有托管的地方，其中互联网大善人就提供了免费托管服务，用来做个静态导航页或者其他自用小网站绰绰有余。

准备条件

  1. CloudFlare 账号：互联网大善人提供资源，那你总该免费注册个账号
  2. worker.js 代码：符合 CloudFlare Worker 托管规则的代码，见下文
  3. 自有域名：大善人提供的预览域名基本上是打不开的，自己买一个最便宜只需￥0.99/年

部署导航页

注册账号这种事情就不值一提了，登录 CloudFlare：

  1. 懒得写英汉对比，直接把语言切到中文：点网页右上角人像图标》语言》简体中文
  2. 点击左侧菜单导航：计算和 AI 》Workers 和 Pages》点击右上角：创建应用程序
  3. Workers 》点 从 Hello World! 开始 这行的 开始使用 》填个女朋友喜欢的 Worker 名称》点 部署
  4. 部署后会自动跳转到刚新建的 Worker 概述页，没跳或者之后想编辑点对应的名称进来即可，在右侧有个 </>编辑代码，点击会到代码编辑和预览页，替换自己的导航页代码点 部署
  5. 绑定域名：将自己买的域名托管到 CloudFlare 后，可以在 Workers 设置界面绑定自定义域名，之后就可以通过绑定的域名访问了
